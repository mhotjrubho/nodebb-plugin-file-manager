# NodeBB File Manager

מנהל קבצים ל־NodeBB עם ממשק Explorer, תצוגה מקדימה, עורך CodeMirror, הרשאות משתמשים ומערכת מפתחות אישיים.

## גרסה 0.7.0
- תיקון טעינת CodeMirror באמצעות RequireJS dependency מפורש.
- הפרדת כיוון פריסת העמוד מכיוון הטקסט: עמודות LTR יציבות, תוכן עברי RTL ונתיבים/קוד LTR.
- ממשק ברוחב מלא, גופנים גדולים יותר, סרגל פעולות וחלוקה ברורה בין ניווט, רשימת קבצים ותצוגה מקדימה.
- מנהלי NodeBB אינם מקבלים יותר גישה אוטומטית למנהל הקבצים.
- אתחול מנהל קבצים ראשון באמצעות מפתח סודי שנמצא בקובץ שרת מחוץ לתיקיית NodeBB.
- הרשאות נפרדות: צפייה, עריכה, מנהל קבצים.
- מנהלי קבצים מאושרים יכולים להוסיף ולהסיר משתמשים, להעניק ניהול מלא ולאפס מפתחות אישיים.

## אתחול ואבטחת גישה

**חשוב:** אחרי התקנת 0.7.0, הרשאת מנהל NodeBB לבדה אינה מקנה גישה למנהל הקבצים. מנהל NodeBB צריך להשלים את האתחול הראשוני עם מפתח השרת.

ברירת המחדל של מיקום מפתח האתחול היא:
`~/.nodebb-file-manager-bootstrap`
הקובץ נקרא מתוך תיקיית הבית של משתמש מערכת ההפעלה שמריץ את NodeBB, וחייב להיות בהרשאות `0600`.

לדוגמה, אם NodeBB פועל כ־root:
```bash
umask 077
openssl rand -hex 32 > /root/.nodebb-file-manager-bootstrap
chmod 600 /root/.nodebb-file-manager-bootstrap
stat -c '%a %U:%G %n' /root/.nodebb-file-manager-bootstrap
```

התוצאה של stat צריכה להתחיל ב־`600`. מפתח האתחול הוא סוד שרת, לא סיסמת NodeBB ולא מפתח המשתמש האישי. יש לשמור אותו במקום מוגן ולא להעבירו בצ'אט או בדפדפן לא מהימן.

בפעם הראשונה:
1. מנהל NodeBB נכנס לעמוד מנהל הקבצים.
2. מזין את מפתח האתחול מהקובץ בשרת.
3. מזין גם את סיסמת חשבון NodeBB שלו לאימות מחדש.
4. החשבון נרשם כמנהל קבצים מורשה.
5. לאחר הכניסה, הוא יכול להוסיף משתמשים דרך חלונית ההרשאות.

מפתח האתחול נשאר כמפתח התאוששות: מנהל NodeBB שמחזיק בו יכול להוסיף את עצמו מחדש כמנהל קבצים במקרה שכל המנהלים המורשים אבדו. לכן יש להגביל את הגישה אליו. כל מנהל קבצים יכול גם להעניק למשתמש אחר את תפקיד "מנהל קבצים", שמעניק גישה מלאה למערכת.

### רמות הרשאה
- **צפייה:** קריאה בלבד תחת `public`.
- **עריכה:** קריאה וכתיבה בתיקיית NodeBB.
- **מנהל קבצים:** גישה מלאה, ניהול משתמשים ואיפוס מפתחות.

הרשאת עריכה או ניהול מלאה יכולה לאפשר שינוי קוד של NodeBB ותוספים. הענק אותה רק לאנשים שאתה סומך עליהם לחלוטין.

## מפתחות אישיים
- לכל משתמש מורשה מפתח מנהל קבצים נפרד מסיסמת NodeBB.
- לפחות 12 תווים.
- נשמרים salt ו־hash מסוג scrypt, עם השוואה בזמן קבוע.
- חמש טעויות גורמות לנעילה ל־15 דקות.
- מנהל קבצים יכול לאפס מפתח של משתמש, אך לא לראות את הסיסמה המקורית.
- שינוי הרשאות ואיפוס דורשים אימות מחדש של סיסמת NodeBB של מנהל הקבצים.

## ממשק ותכונות
- ממשק Explorer ברוחב מלא, עם עמודות ניווט, רשימת קבצים ותצוגה מקדימה.
- RTL לטקסט בעברית ו־LTR לנתיבים, שמות קבצים וקוד.
- תצוגת פרטים ותצוגת סמלים, חיפוש, נתיב תיקייה וניווט מהיר.
- תצוגה מקדימה לתמונות PNG, JPEG, GIF, WebP, AVIF, BMP, SVG ו־ICO עד 8MB.
- תצוגה מקדימה לקובצי טקסט וקוד נתמכים.
- עורך CodeMirror 5.65.20 מקומי, עם מספרי שורות, הדגשת תחביר, קיפול, חיפוש, סוגריים וסגירת תגיות, מסך מלא ושמירה ב־Ctrl+S.
- אם CodeMirror לא נטען, עורך טקסט חלופי מאפשר להמשיך לעבוד.
- העלאת קבצים ותיקיות תוך שמירת המבנה, התקדמות וביטול העלאה פעילה.
- יצירה, שינוי שם, העתקה, העברה, מחיקה לסל מחזור, שחזור, מחיקה לצמיתות, גיבויים וחילוץ ZIP.
- אין מסוף פקודות ואין הרצת shell מתוך ממשק הדפדפן.

## מגבלות
- שורש העבודה נשאר תיקיית ההתקנה של NodeBB. אין גישה לנתיבים שמחוץ לה.
- קובץ לעריכה עד 2MB, תמונה לתצוגה מקדימה עד 8MB.
- העלאה עד 100MB לקובץ ו־500MB לבקשה מצד התוסף; מגבלות NodeBB יכולות להיות נמוכות יותר.
- ZIP עד 100MB, עד 5,000 פריטים ועד 500MB תוכן מחולץ.
- ביטול העלאה מפסיק בקשות ומנות שטרם נשלחו; קבצים שכבר נשמרו בשרת אינם נמחקים אוטומטית.
- אין ניהול הרשאות מערכת Unix מסוג chmod/chown, אין הורדת תיקייה כ־ZIP ואין חיבור FTP/SFTP חיצוני.

## הפעלת פרויקט Node.js נפרד
מנהל הקבצים אינו מריץ `npm install`, `npm start` או פקודות מערכת. פרויקט Node.js נפרד יש להעלות לתיקייה נפרדת מחוץ לשורש NodeBB באמצעות SSH/SFTP או מנגנון הפריסה של השרת, להתקין בו תלויות ולהפעיל באמצעות PM2 או שירות מערכת. כדי להציג אותו בעמוד NodeBB, יש לפרסם אותו דרך reverse proxy עם HTTPS ולהטמיע כתובת iframe בווידג'ט HTML. אין להפעיל shell כללי מתוך ממשק הדפדפן.

## תאימות ובדיקות
- NodeBB 4.16.x (נבדק מול מקור 4.16.7)
- Node.js 20 ומעלה
- תלויות: yauzl, codemirror 5.65.20

CI בודק התקנת תלויות, תחביר JavaScript, קיום נכסי CodeMirror, בדיקות הרשאות, מפתח אתחול, מפתחות משתמשים והתאמה בין הממשק לקוד. בדיקות CI אינן תחליף לבדיקת דפדפן מול שרת NodeBB חי.

## אבטחה
התוסף מבצע פעולות קבצים בתוך תהליך NodeBB, שלעיתים פועל בהרשאות מערכת רחבות. בדיקות נתיבים וקישורים סמליים מפחיתות סיכון אך אינן מבטלות לחלוטין מרוץ זמן (TOCTOU). יש להגביל גישה לשרת, לשמור גיבויים ולתת הרשאות עריכה רק לאנשים מהימנים.
