# NodeBB File Manager

תוסף ניהול קבצים מתוך לוח הבקרה של NodeBB.

## גרסה
0.3.0 - גרסת MVP מורחבת לבדיקות מבוקרות.

## יכולות
- ניווט בתיקיות והצגת קבצים.
- עריכת קובצי טקסט UTF-8 עד 2MB.
- שמירה אטומית וגיבוי אוטומטי לפני דריסת קובץ.
- יצירת תיקיות, שינוי שמות ומחיקה.
- העלאת קבצים בודדים או מספר קבצים.
- העלאת תיקייה שלמה תוך שמירה על מבנה התיקיות.
- חילוץ ZIP עם חסימת נתיבי Zip Slip, קישורים סמליים, דריסה וגודל חילוץ חריג.
- העתקה והעברה.
- חיפוש שמות קבצים ותיקיות.
- הצגת גיבויים ושחזור גיבוי.
- ממשק ACP בעברית.

## גבולות ואבטחה
- פעולות השרת מוגבלות למנהלי NodeBB.
- שורש העבודה הוא תיקיית ההתקנה של NodeBB בלבד.
- נתיבים מוחלטים, מעבר באמצעות .. וקישורים סמליים חסומים.
- אין מסוף פקודות ואין הרצת פקודות מערכת.
- עריכה מוגבלת ל-2MB לקובץ.
- העלאה מוגבלת ל-100MB לקובץ ול-500MB לבקשה.
- NodeBB 4.16 משתמש במגבלת multipart של 20 קבצים לבקשה; ממשק ההעלאה מחלק תיקיות למנות של 20.
- ZIP מוגבל ל-100MB, עד 5,000 פריטים ועד 500MB תוכן מחולץ.
- לפני שמירה או שחזור של קובץ קיים נוצר גיבוי.
- גיבויים נשמרים תחת .file-manager-backups בהרשאות תיקייה 0700.

## דרישות
- NodeBB 4.16.x
- Node.js 20 ומעלה
- תלות: yauzl

## התקנה
יש לגבות את הפורום לפני התקנה. מומלץ לבצע בדיקה ראשונה בסביבת staging. לאחר התקנת התוסף יש לבנות מחדש את קובצי NodeBB ולהפעיל מחדש את הפורום בהתאם לנוהל ההתקנה של NodeBB.

## הערה
זו גרסת MVP. למרות בדיקות התאימות מול מבנה הקוד של NodeBB 4.16.7, יש לבצע בדיקת התקנה בפועל לפני שימוש בקבצים חשובים. התוסף רץ בהרשאות תהליך NodeBB ולכן יש להתייחס לכל פעולת מחיקה, העברה או חילוץ בזהירות.
