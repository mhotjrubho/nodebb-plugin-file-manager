# NodeBB File Manager

תוסף לניהול קבצים מתוך לוח הבקרה של NodeBB.

## גרסה

0.2.0 - גרסת MVP ראשונית לבדיקות התקנה מבוקרות.

## יכולות קיימות

- הצגת תיקיות וקבצים תחת תיקיית ההתקנה של NodeBB.
- ניווט בין תיקיות.
- הצגת סוג וגודל קובץ.
- פתיחת קובצי טקסט UTF-8 לעריכה.
- שמירת שינויים עם יצירת גיבוי אוטומטי לפני דריסת קובץ.
- יצירת תיקיות.
- שינוי שמות ומחיקת קבצים ותיקיות.
- ממשק ניהול בעברית ובכיווניות RTL.

## מה עדיין לא כלול

- העלאת קבצים ותיקיות מהמחשב.
- העלאת ZIP וחילוץ.
- העתקה והעברה.
- חיפוש מתקדם.
- מסך ניהול ושחזור גיבויים.
- יומן פעולות מלא.

## אבטחה

- כל פעולות השרת מוגבלות למנהלי NodeBB שהם administrators.
- נתיב העבודה מוגבל לתיקיית ההתקנה של NodeBB לפי `base_dir`.
- נתיבים מוחלטים, מעבר תיקייה באמצעות `..` וקישורים סמליים נחסמים.
- מגבלת עריכת קובץ: 2MB.
- אין מסוף פקודות ואין הרצת פקודות מערכת.
- לפני שמירה על קובץ קיים נשמר גיבוי בתיקייה `.file-manager-backups`.

## דרישות

- NodeBB 4.16.x
- Node.js 20 ומעלה

## התקנה

יש לבצע תחילה התקנה בסביבת בדיקה או לאחר גיבוי מלא של הפורום. גרסה זו היא MVP ואינה כוללת עדיין את כל יכולות מנהל הקבצים המתוכננות.

לאחר התקנה והפעלה מחדש, יש להיכנס ללוח הבקרה ולבחור בתפריט התוספים את "מנהל קבצים".
