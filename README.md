# NodeBB File Manager

מנהל קבצים ל־NodeBB עם ממשק קומפקטי בסגנון Windows File Explorer, הרשאות לפי משתמש, מפתח אישי נפרד לפעולות קבצים, תצוגה מקדימה ועורך קוד.

## גרסה
0.6.0 - ממשק Explorer, תצוגת תמונות וקבצים, עורך מתוקן ומערכת מפתחות אישיים.

## ממשק
- ממשק עברי RTL עם הפרדה מפורשת של נתיבים, שמות קבצים וקוד ב־LTR.
- רוחב עבודה מרבי של 1360px, סרגל פעולות עליון, סרגל נתיב, ניווט מהיר, תצוגת פרטים ותצוגת סמלים.
- בחירת קובץ מציגה חלונית פרטים ותצוגה מקדימה; לחיצה כפולה פותחת תיקייה או קובץ.
- תצוגה מקדימה לתמונות PNG, JPEG, GIF, WebP, AVIF, BMP, SVG ו־ICO עד 8MB.
- תצוגת מקדימה לקריאה בלבד של קובצי טקסט וקוד נתמכים עד מגבלת העריכה, עם קיטוע למניעת חלונית כבדה.
- חלונית העורך מופיעה לצד רשימת הקבצים, ולא בסוף העמוד.
- חלוניות הגיבויים/סל המחזור וניהול המשתמשים מוצגות כשכבות צפות, ללא גלילה לתחתית.
- העלאה מציגה התקדמות לפי מנות קבצים, וניתן לבטל את בקשת ההעלאה הפעילה. אם מנה כבר נקלטה בשרת, הביטול אינו מוחק קבצים שכבר הועלו.

## עורך קוד
- CodeMirror 5.65.20, נטען מקובצי התוסף המקומיים ללא CDN.
- הגדרת AMD path ייעודית ל־CodeMirror בתוך RequireJS.
- מספרי שורות, הדגשת תחביר, התאמת וסגירת סוגריים, קיפול קוד, חיפוש, גלישת שורות, מסך מלא ושמירה ב־Ctrl+S.
- תמיכה ב־JavaScript, JSON, HTML, XML, CSS, PHP, Python, Shell, YAML, Markdown ו־SQL.
- אם ספריית העורך לא נטענת, מוצג עורך טקסט חלופי כדי לא להשאיר את המשתמש ללא אפשרות עריכה. במקרה כזה אין הדגשת תחביר או כלי CodeMirror.
- עריכת קובצי UTF-8 עד 2MB, שמירה אטומית וגיבוי לפני דריסה.

## מערכת סיסמאות אישית
- לכל משתמש מורשה יש מפתח אישי של מנהל הקבצים, נפרד מסיסמת NodeBB.
- נדרש מינימום 12 תווים ואימות כפול בזמן הגדרה או החלפה.
- הסיסמה אינה נשמרת גלויה: נשמרים salt אקראי ו־hash מסוג scrypt, עם השוואה בזמן קבוע.
- הגדרת מפתח או החלפתו דורשת אימות סיסמת NodeBB של המשתמש עצמו.
- כל פעולה שמשנה קבצים, לרבות העלאה, כתיבה, יצירה, שינוי שם, העתקה, העברה, חילוץ, שחזור ומחיקה, דורשת את המפתח האישי.
- לאחר 5 ניסיונות שגויים, המשתמש וכתובת ה־IP ננעלים ל־15 דקות. מונה הניסיונות נשמר בזיכרון התהליך ומתאפס בהפעלה מחדש.
- מנהל NodeBB יכול לאפס מפתח של משתמש. המנהל אינו יכול לצפות בסיסמה האישית של אותו משתמש.
- שינוי רשימת המשתמשים המורשים ואיפוס מפתח משתמש דורשים אימות סיסמת NodeBB של מנהל המערכת.

## הרשאות משתמשים
- **מנהל NodeBB:** גישה מלאה וניהול המשתמשים המורשים.
- **משתמש מורשה לעריכה:** גישה מלאה לתיקיית NodeBB ולפעולות שינוי.
- **משתמש מורשה לצפייה:** קריאה בלבד לתיקייה public ולתוכן שתחתיה.
- ניתן לחפש משתמשים לפי שם משתמש ולהוסיף אותם בלי להעתיק UID ידנית.
- הרשאות נשמרות ב־meta.settings של NodeBB.

**חשוב:** הרשאת עריכה מאפשרת לשנות קובצי קוד של NodeBB ותוספים. יש להעניק אותה רק לאנשים מהימנים ברמת מנהל טכני.

## פעולות קבצים
- ניווט בתיקיות ובקבצים תחת תיקיית ההתקנה של NodeBB.
- יצירת קובץ ותיקייה, שינוי שם, העתקה והעברה.
- העברה לסל מחזור, שחזור, וגיבויים לפני דריסת קובץ.
- העלאת קבצים בודדים, מספר קבצים או תיקייה שלמה תוך שמירת המבנה.
- חילוץ ZIP עם בדיקות נתיבים, קישורים סמליים, מניעת דריסה ומגבלות גודל.
- חיפוש קבצים ותיקיות עם מגבלת עומק ומספר פריטים לסריקה.

## הגבלות אבטחה
- שורש העבודה מוגבל לנתיב base_dir של NodeBB.
- נתיבים מוחלטים, מעבר באמצעות .., קישורים סמליים ונתיבים לתיקיית הגיבויים הפנימית חסומים.
- בדיקת הרשאות ומפתח אישי מתבצעת לפני קבלת נתוני multipart בהעלאה.
- תיקיית .file-manager-backups מוסתרת מרשימת הקבצים ומוגנת מפעולות רגילות.
- מחיקה רגילה מעבירה פריטים לסל המחזור במקום למחוק מיד.
- אין מסוף פקודות ואין API להרצת פקודות מערכת.
- גודל קובץ לעריכה מוגבל ל־2MB. תצוגת תמונה מוגבלת ל־8MB.
- העלאה מוגבלת ל־100MB לקובץ ול־500MB לבקשה מצד התוסף. מגבלת NodeBB maximumFileSize יכולה להיות נמוכה יותר וגוברת על מגבלת התוסף.
- NodeBB מגביל multipart ל־20 קבצים לבקשה; הממשק מחלק העלאה למנות של עד 20.
- ZIP מוגבל ל־100MB, עד 5,000 פריטים, עד 100MB לקובץ ועד 500MB תוכן מחולץ.
- תיקיית הגיבויים נשמרת בהרשאות 0700 וקובצי המטא־נתונים בהרשאות 0600.

## תאימות ובדיקות
- NodeBB 4.16.x (נבדק מול קוד המקור של v4.16.7)
- Node.js 20 ומעלה
- תלויות: yauzl, codemirror 5.65.20

בדיקות CI כוללות התקנת תלויות, בדיקת תחביר, בדיקת manifest, קיום מודולי CodeMirror, בדיקות הרשאות, הגדרת סיסמה נפרדת, תצוגה מקדימה, העלאה ובדיקת התאמת מזהי DOM לתבנית. בדיקות אלה אינן תחליף לבדיקה בדפדפן על שרת NodeBB חי.

## התקנה ועדכון
יש לבצע גיבוי מלא של NodeBB לפני עדכון. מומלץ לבדוק תחילה בסביבת staging. לפני עדכון התוסף בשרת יש לעצור את NodeBB, להתקין את הגרסה, להריץ build ולהפעיל מחדש לפי נוהל ההתקנה.

## הערת אבטחה חשובה
התוסף מבצע פעולות קבצים מתוך תהליך NodeBB, שלעיתים פועל בהרשאות מערכת רחבות. בדיקות נתיבים וקישורים סמליים מפחיתות סיכון אך אינן מבטלות לחלוטין מרוץ זמן (TOCTOU) כאשר משתמש מקומי אחר משנה את מערכת הקבצים במקביל. יש להגביל גישה לשרת ולתהליך NodeBB, להעניק הרשאות עריכה רק למשתמשים מהימנים ולשמור גיבויים מחוץ לשרת.
