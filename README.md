# NodeBB File Manager

תוסף ניהול קבצים לממשק הניהול של NodeBB.

## מצב הפרויקט

גרסת אב-טיפוס ראשונית. כוללת הצגת תיקיות וקבצים, קריאת קובצי טקסט, עריכת קובצי טקסט עם גיבוי לפני שמירה, יצירת תיקיות, שינוי שמות ומחיקה.

עדיין לא כוללת העלאת קבצים, העלאת תיקיות, חילוץ ZIP, העתקה או העברה.

## אבטחה

- פעולות השרת מוגבלות למנהלי NodeBB שהם administrators.
- גישת הקבצים מוגבלת לתיקיית ההתקנה של NodeBB (`base_dir`).
- נתיבים מוחלטים, `..` וקישורים סמליים נחסמים.
- לפני דריסת קובץ קיים נשמר עותק בתיקייה `.file-manager-backups`.
- אין בתוסף מסוף פקודות ואין הרצת פקודות מערכת.
- מגבלת עריכת קובץ: 2MB.

## דרישות

- NodeBB 4.16.x
- Node.js 20 ומעלה

## התקנה

יש להתקין דרך מנגנון התוספים של NodeBB לאחר בדיקה בסביבת בדיקה. אין להתקין גרסת אב-טיפוס זו על פורום פעיל לפני בדיקות אבטחה ותאימות.
